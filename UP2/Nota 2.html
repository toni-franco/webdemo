Big Data <> Analitics o Data Science

El Data Analytics utiliza esos datos (u otros) para aplicar modelos matemáticos y estadísticos con el fin de obtener conclusiones y mejorar la toma de decisiones

El Data Science (Ciencia de Datos) utiliza las matemáticas y la inteligencia artificial para analizar esos datos, descubrir patrones y predecir comportamientos.

El Data Science (Ciencia de Datos) y el Data Analytics (Análisis de Datos) se diferencian principalmente en su enfoque temporal y complejidad. El Data Analytics se centra en explorar datos históricos para resolver problemas de negocio actuales, mientras que el Data Science diseña modelos predictivos y algoritmos de Machine Learning para anticipar el futuro
